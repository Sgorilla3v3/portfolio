연결 테스트
및 확인

Claude와 Obsidian이 정상적으로
소통하는지 검증하는 단계입니다.

학습 목표

MCP 서버와 Claude Desktop 간의 통신 상태를 확인하고
주요 명령어들이 올바르게 동작하는지 검증합니다.

핵심 포인트

  • 파일 목록 조회: 볼트 내의 파일들을 제대로 인식하는지 확인합니다.
  • 내용 읽기 및 검색: 특정 노트의 내용에 접근할 수 있는지 테스트합니다.
  • 노트 생성: AI를 통해 새로운 파일을 생성할 수 있는지 검증합니다.

완료 기준

Claude에게 "내 볼트의 파일 목록을 보여줘"라고 요청했을 때,
실제 파일 리스트가 채팅창에 정상적으로 출력되어야 합니다.
