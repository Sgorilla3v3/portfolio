볼트(Vault) 생성 및 설정 Obsidian

옵시디언의 지식 저장소인 볼트를 생성하고 경로를 확인하는 방법을 알아봅니다.

1
옵시디언 실행

설치된 Obsidian을 실행합니다. 첫 실행 시 볼트를 생성하거나 열 수 있는 시작 화면이 나타납니다.

2
새 볼트 생성 (Create new vault)

"Create new vault" 버튼을 클릭하고, 볼트의 이름과 파일이 저장될 로컬 위치(폴더)를 지정합니다.

3
기존 폴더 열기 (Open folder as vault)

이미 마크다운 파일들이 있는 폴더가 있다면 "Open folder as vault"를 선택하여 바로 연결할 수 있습니다.

4
볼트 경로 확인 (중요!)

생성된 볼트의 절대 경로는 나중에 Claude MCP 설정 파일에 정확히 입력해야 하므로 별도로 메모해두세요.

경로 설정 시 주의사항

볼트 경로는 나중에 MCP 설정(JSON)에서 정확하게 입력해야 합니다.
한글 경로보다는 영문 경로를 사용하는 것이 인코딩 오류를 방지하는 데 유리합니다.
