Git 설치 및 확인 Windows / macOS / Linux

볼트의 버전 관리와 안전한 백업을 위해 Git 설치가 필수적입니다.

Windows

Git for Windows 설치 프로그램을 다운로드하여 설치합니다. 대부분 'Next'를 눌러 기본 설정으로 진행하면 됩니다.

# 1. 설치 파일 다운로드 및 실행 # https://gitforwindows.org/ 방문
# 2. 설치 완료 후 PowerShell에서 확인 PS>git --version # 출력 예: git version 2.43.0.windows.1
# 3. 사용자 정보 설정 (최초 1회) PS>git config --global user.name "Your Name" PS>git config --global user.email "email@ex.com"
/
macOS / Linux

터미널에서 패키지 매니저를 통해 간편하게 설치할 수 있습니다.

# [macOS] Homebrew 사용 $brew install git
# [Linux] Ubuntu/Debian $sudo apt update $sudo apt install git
# 설치 확인 및 설정 $git --version $git config --global user.name "Your Name"
