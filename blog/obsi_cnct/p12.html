학습 목표

Claude Desktop 앱을 설치하고,
MCP(Model Context Protocol)의 개념과 필요성을 이해합니다.

MCP 핵심 개념

  • 표준 프로토콜: AI와 로컬 데이터/도구를 연결하는 표준 규격입니다.
  • 로컬 보안: 데이터가 외부로 전송되지 않고 로컬에서 안전하게 처리됩니다.
  • 확장성: 옵시디언 외에도 파일시스템, GitHub 등 다양한 도구 연동 가능.

필수 준비사항

웹 브라우저가 아닌 전용 Desktop 앱 설치가 필수적입니다.
설치 후 계정 로그인 상태를 확인해주세요.
