보안, 백업 및 확장 설정

데이터를 안전하게 보호하고, 추가 MCP 서버로 기능을 확장하는 방법입니다.

1
보안 및 로컬 원칙

MCP는 로컬 환경에서 실행되므로 데이터는 외부로 전송되지 않습니다. 단, 민감한 정보는 분리된 볼트에서 관리하는 것을 권장합니다.

2
Git을 이용한 백업

git init으로 볼트를 버전 관리 하에 두고, 정기적으로 커밋하여 데이터 손실을 방지하세요.

3
MCP 서버 확장

설정 파일(JSON)에 filesystem이나 github 같은 다른 서버를 추가하여 기능을 확장할 수 있습니다.

자동화 팁

백업 스크립트를 작성하여 스케줄러(cron 등)에 등록하면, 매일 자동으로 노트 변경사항을 백업할 수 있습니다.

Terminal
# 1. Git 초기화 및 첫 커밋
➜ cd /path/to/your/vault
➜ git init
Initialized empty Git repository in /vault/.git/
➜ git add .
➜ git commit -m "Initial backup"
[main (root-commit)] Initial backup 12 files changed, 108 insertions(+)
# 2. 확장 설정 예시 (filesystem 서버 추가)
➜ cat claude_desktop_config.json
{ "mcpServers": { "obsidian": { ... }, "filesystem": { "command": "npx", "args": ["@mcp-packages/filesystem", "/path/docs"] } } }
