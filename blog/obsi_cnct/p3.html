사전 요구사항 체크리스트

이 가이드를 원활하게 진행하기 위해 필요한 선수 지식과 준비물입니다.

필수 항목 Mandatory Requirements
  • 기본적인 컴퓨터 사용 능력

    프로그램 설치, 파일 압축 해제, 시스템 설정 변경 등 기초적인 OS 조작이 가능해야 합니다.

  • 터미널 / 명령 프롬프트 기초

    cd(이동), ls/dir(목록 확인) 등 기본적인 명령어 입력 방식에 대한 이해가 필요합니다.

  • 파일 시스템 이해

    절대 경로와 상대 경로의 개념, 파일 확장자 및 폴더 구조에 대해 이해하고 있어야 합니다.

권장 사항 Highly Recommended
  • 관리자 권한 계정

    Node.js 및 시스템 전역 패키지(npm -g) 설치 시 관리자(sudo/Administrator) 권한이 필요합니다.

  • 안정적인 인터넷 연결

    약 200MB 이상의 설치 파일 및 라이브러리 다운로드를 위해 안정적인 네트워크가 필요합니다.

  • GitHub 계정

    볼트 백업 및 버전 관리를 위해 권장되며, MCP 서버 소스코드 확인 시에도 유용합니다.
