MCP 서버 연결 실패

Claude에서 "옵시디언에 접근할 수 없습니다" 메시지가 뜬다면 다음을 확인하세요:

  • 설정 파일(JSON)의 쉼표(,) 등 문법 오류 재확인
  • 볼트 경로가 실제 경로와 일치하는지 확인
  • Claude Desktop을 완전히 종료 후 재시작

한글 파일명 깨짐

UTF-8 인코딩 문제일 수 있습니다.
가능하면 파일명에 특수문자를 피하고, 지속적인 문제 발생 시 테스트를 위해 영문 파일명으로 변경해 보세요.

JSON 구문 오류

경로에 역슬래시(\) 사용 시 이스케이프 처리가 안 되어 발생하는 오류가 가장 흔합니다. 슬래시(/) 사용을 권장합니다.

권한 오류 해결 (Linux/macOS)
방법 1: sudo 권한 사용 (빠른 해결)
# 관리자 권한으로 설치 시도
$sudo npm install -g @mcp-packages/obsidian
방법 2: nvm 사용 (권장)
# nvm 설치 후 Node.js 재설치
$curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.0/install.sh | bash
$nvm install node

권한 오류는 주로 전역(Global) 설치 시 시스템 폴더 접근 권한 때문에 발생합니다. NVM을 사용하면 사용자 영역에 설치되어 이 문제를 예방할 수 있습니다.
