학습 점검 체크리스트

옵시디언과 Claude MCP 연동 과정의 핵심 단계를 최종 점검합니다.

환경 및 연동 설정 Environment Setup
  • Node.js & Git 설치

    터미널에서 node -v 및 git --version 명령어로 설치된 버전을 확인했습니다.

  • Obsidian 볼트 준비

    옵시디언을 설치하고 MCP와 연동할 볼트 경로를 정확히 파악했습니다.

  • MCP 서버 패키지 설치

    npm install -g 명령어로 옵시디언 MCP 서버를 성공적으로 설치했습니다.

  • 설정 파일(JSON) 구성

    OS별 경로에 맞게 claude_desktop_config.json 파일을 올바르게 작성했습니다.

기능 테스트 및 활용 Testing & Advanced
  • 기본 연결 확인

    Claude에게 볼트 내 파일 목록을 요청하여 정상적으로 읽어오는지 확인했습니다.

  • 노트 생성 테스트

    프롬프트를 통해 새로운 노트를 생성하고 내용이 옵시디언에 반영되는지 검증했습니다.

  • 태그 및 검색 활용

    특정 태그나 키워드가 포함된 노트를 검색하고 분석하는 기능을 테스트했습니다.

  • 백업 및 워크플로우

    데이터 안전을 위한 백업(Git 등)을 설정하고 나만의 활용 워크플로우를 구상했습니다.
