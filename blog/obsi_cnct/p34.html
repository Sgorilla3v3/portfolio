로그 확인과 디버그 실행

문제 발생 시 원인을 파악하기 위한 로그 파일 확인 및 상세 디버그 모드 실행 방법입니다.

1
로그 파일 위치 확인

Claude Desktop의 로그는 OS별로 다른 위치에 저장됩니다. Windows는 %APPDATA%\Claude\logs를 확인하세요.

2
디버그 모드 실행

--debug 플래그를 사용하여 MCP 서버를 직접 실행하면 상세한 실행 과정을 터미널에서 즉시 확인할 수 있습니다.

로그 분석 팁

에러 메시지에서 EACCES(권한 문제) 또는 ENOENT(파일/경로 없음) 키워드를 우선적으로 찾아보세요. 대부분의 연결 실패 원인입니다.

Terminal - Debug Mode
# 1. Claude 로그 실시간 확인 (macOS 예시)
➜ tail  -f  ~/Library/Logs/Claude/mcp.log
2024-12-23 10:00:01 [INFO] Connecting to MCP server... 2024-12-23 10:00:02 [ERROR] Failed to connect: Connection refused
# 2. 디버그 모드로 직접 실행하여 상세 오류 확인
➜ npx  @mcp-packages/obsidian  /path/to/vault  --debug
[DEBUG] Starting Obsidian MCP Server v0.1.0 [DEBUG] Resolving vault path: /Users/me/Documents/MyVault [DEBUG] Verifying permissions... [ERROR] Vault not found: /Users/me/Documents/MyVault Error: ENOENT: no such file or directory
➜
