Claude Desktop 설치 Win / Mac / Linux

MCP 연동을 위해서는 웹 버전이 아닌 Claude Desktop 애플리케이션 설치가 필수입니다.

Windows

claude.ai에서 Windows용 인스톨러(.exe)를 다운로드하여 설치합니다.

# 1. 설치 파일 실행 Run Claude-Setup-x64.exe # 2. 설치 마법사 Follow instructions... # 3. 로그인 Sign in with email
macOS

DMG 파일을 다운로드하고 Applications 폴더로 드래그하여 설치합니다.

# 1. 이미지 마운트 Open Claude.dmg # 2. 설치 (Drag & Drop) Claude.app → /Applications # 3. 앱 실행 Open Launchpad > Claude
Linux

AppImage 또는 .deb 패키지를 지원합니다. (Ubuntu/Debian 계열)

# 방법 A: AppImage 실행 $chmod +x Claude.AppImage $./Claude.AppImage # 방법 B: .deb 설치 $sudo dpkg -i claude.deb
