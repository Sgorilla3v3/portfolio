기본 환경
구축

AI 도구 연동을 위한
튼튼한 개발 기반을 마련합니다.

학습 목표

Node.js와 Git을 설치하고 버전을 확인함으로써
MCP 서버 구동에 필요한 실행 환경을 완성합니다.

핵심 포인트

  • Node.js LTS 버전: 안정적인 실행을 위해 장기 지원 버전을 선택합니다.
  • Git 설치: 볼트의 안전한 백업과 버전 관리를 위한 필수 도구입니다.
  • 환경 변수: 터미널 어디서든 명령어가 실행되도록 설정합니다.

완료 기준

터미널에서 node -v, npm -v, git --version 명령 입력 시
버전 정보가 정상적으로 출력되어야 합니다.
