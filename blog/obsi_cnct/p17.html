GitHub에서 직접 클론

최신 기능을 테스트하거나 개발에 참여할 때 유용한 설치 방법입니다.

1
저장소 복제 (Clone)

GitHub에서 git clone 명령어를 사용해 소스 코드를 로컬 컴퓨터로 다운로드합니다.

2
의존성 설치 (Install)

다운로드된 폴더로 이동한 후, npm install을 실행하여 필요한 패키지를 모두 설치합니다.

이 방법이 필요한 경우

아직 npm에 배포되지 않은 최신 기능을 미리 사용해보거나, 직접 코드를 수정하여 오픈소스에 기여하고 싶을 때 적합합니다.

Terminal - bash
# 1. GitHub 저장소 복제하기
➜ git  clone  https://github.com/Nahuelhds/mcp-obsidian-server.git
Cloning into 'mcp-obsidian-server'... remote: Enumerating objects: 156, done. Receiving objects: 100% (156/156), 42.5 KiB | 2.5 MiB/s, done. Resolving deltas: 100% (82/82), done.
# 2. 프로젝트 폴더로 이동
➜ cd  mcp-obsidian-server
# 3. 의존성 패키지 설치
➜ npm  install
added 86 packages, and audited 87 packages in 2s found 0 vulnerabilities
➜
