npm 전역 설치 (권장)

가장 간단하고 빠르게 Obsidian MCP 서버를 설치하는 방법입니다.

1
설치 명령어 실행

터미널을 열고 npm install 명령어를 사용하여 패키지를 전역(-g)으로 설치합니다.

2
설치 확인

npm list 명령어로 패키지가 정상적으로 설치되었는지 확인합니다. 버전 정보가 출력되면 성공입니다.

전역 설치(-g)를 하는 이유

MCP 서버는 특정 프로젝트가 아닌 시스템 전체에서 도구로 사용되므로, 전역으로 설치하여 어디서든 실행 가능하게 만드는 것이 편리합니다.

Terminal
# 1. MCP Obsidian 패키지 전역 설치
➜ npm  install  -g  @mcp-packages/obsidian
added 1 package, and audited 2 packages in 3s found 0 vulnerabilities
# 2. 설치 확인 (방법 A: 리스트 확인)
➜ npm  list  -g  @mcp-packages/obsidian
/usr/local/lib └── @mcp-packages/obsidian@0.1.0
# 3. 실행 테스트 (방법 B: 버전 확인)
➜ npx  @mcp-packages/obsidian  --version
0.1.0
➜
