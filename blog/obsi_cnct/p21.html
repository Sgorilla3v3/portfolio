설정 JSON 작성 가이드

Claude Desktop 설정 파일에 Obsidian MCP 서버를 등록하는 방법입니다.

1
기본 구조 확인

설정 파일(`config.json`)을 열고 "mcpServers" 객체 내에 새로운 설정을 추가할 준비를 합니다. 기존 설정이 있다면 쉼표(,)로 구분하여 추가합니다.

2
서버 정보 입력

"obsidian" 키를 생성하고 실행 명령어(npx)와 인자(패키지명, 볼트 경로)를 배열 형태로 입력합니다.

경로 입력 주의사항

볼트 경로는 반드시 절대 경로여야 합니다. 또한 JSON 문법상 백슬래시(\)는 이스케이프 처리가 필요하므로, Windows에서도 슬래시(/)를 사용하는 것이 안전합니다.

claude_desktop_config.json
1 {
2 "mcpServers": {
3 "obsidian": {
4 "command": "npx",
5 "args": [
6 "-y",
7 "@mcp-packages/obsidian",
8 "/Users/YourName/Documents/MyVault"
9 ]
10 }
11 }
12 }
13
