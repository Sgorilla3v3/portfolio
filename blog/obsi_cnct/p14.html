Claude 계정 설정 및 확인 Preparation

MCP 서버 연동을 시작하기 전, Claude Desktop 앱의 상태와 계정 준비를 완료합니다.

1
계정 로그인 및 동기화

Claude Desktop 앱을 실행하고 로그인합니다. claude.ai 웹 버전과 동일한 계정을 사용하여 대화 기록이 동기화되는지 확인하세요.

2
최신 버전 확인

MCP 기능은 최신 버전에서 지원됩니다. 메뉴바의 Check for Updates...를 클릭하여 앱을 최신 상태로 업데이트합니다.

3
MCP 연동 준비 상태 확인

별도의 'MCP 활성화' 버튼은 없습니다. 앱이 정상 실행되고 대화 입력창이 보인다면 MCP 서버를 연결할 준비가 완료된 것입니다.

4
설정 파일 경로 파악

OS별 설정 파일이 저장될 위치를 미리 확인해둡니다. 파일이 아직 없더라도 괜찮습니다. 다음 단계에서 생성합니다.

Claude Pro가 필요한가요?

아니요, MCP(Model Context Protocol) 기능은 무료 사용자(Free Tier)도 사용할 수 있습니다. 로컬 환경의 옵시디언과 연동하는 것은 추가적인 API 비용이 발생하지 않습니다.
