Node.js 설치 Windows

안정적인 개발 환경 구축을 위한 Node.js 설치 과정을 단계별로 알아봅니다.

1
공식 웹사이트 방문

브라우저를 열고 nodejs.org에 접속합니다. 자동으로 운영체제를 감지하여 Windows용 다운로드 버튼이 표시됩니다.

2
LTS 버전 다운로드 (권장)

두 가지 버전 중 LTS (Long Term Support) 버전을 선택하여 설치 파일을 다운로드합니다.

3
설치 진행

다운로드한 .msi 파일을 실행하고 기본 설정 그대로 'Next'를 눌러 설치를 완료합니다.

4
설치 확인

명령 프롬프트(CMD) 또는 PowerShell을 열고 버전을 확인하여 설치가 정상적으로 되었는지 검증합니다.

왜 LTS 버전을 선택해야 하나요?

LTS(장기 지원) 버전은 안정성과 보안이 검증된 버전입니다. 최신 기능(Current)보다는 오류가 적어 옵시디언 MCP 서버와 같은 도구를 구동하기에 가장 적합합니다.

Command Prompt

C:\Users\User> node --version

v20.10.0

C:\Users\User> npm --version

10.2.3
