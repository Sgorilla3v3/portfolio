Node.js 설치 macOS / Linux

UNIX 기반 시스템에서는 패키지 매니저를 통한 설치가 가장 효율적입니다.

macOS

Homebrew를 사용하는 것이 가장 권장되는 방식입니다. 버전 관리와 업데이트가 용이합니다.

# Homebrew를 통한 설치 (권장) $brew install node # 설치 확인 $node --version $npm --version # (옵션) 공식 웹사이트 대안 # nodejs.org에서 .pkg 파일 다운로드 가능
Linux (Ubuntu/Debian)

NodeSource 저장소를 통해 최신 LTS 버전을 설치합니다. 기본 apt 저장소는 구버전일 수 있습니다.

# NodeSource 저장소 스크립트 실행 $curl -fsSL https://deb.nodesource.com/setup_lts.x | sudo -E bash - # Node.js 설치 $sudo apt-get install -y nodejs # 설치 확인 $node --version $npm --version
