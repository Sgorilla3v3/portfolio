경로 처리 주의사항

설정 파일 작성 시 가장 많이 발생하는 경로 오류를 방지하는 방법입니다.

Windows 사용자 필독

JSON 파일에서 백슬래시(\)는 이스케이프 문자로 인식됩니다.
단순히 폴더 경로를 복사해서 붙여넣으면 오류가 발생합니다.

❌ 잘못된 예시 (Syntax Error)
"C:\Users\Name\Vault"

'\U', '\N' 등을 특수문자로 잘못 해석함

✅ 추천 방법 (슬래시 변환)
"C:/Users/Name/Vault"

가장 깔끔하고 오류가 없는 방식

✅ 대안 (이중 백슬래시)
"C:\\Users\\Name\\Vault"

이스케이프 문자를 한 번 더 이스케이프

운영체제별 설정 파일 예시
Windows
"args": [
"...",
"C/Users/YourName/Documents/MyVault"
]
macOS
"args": [
"...",
"/Users/YourName/Documents/MyVault"
]
Linux
"args": [
"...",
"/home/username/Documents/MyVault"
]

설정 변경 후에는 반드시 Claude Desktop을 완전히 종료하고 재시작해야 적용됩니다.
