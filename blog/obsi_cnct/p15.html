Chapter 04

MCP Server
설치

Obsidian과 Claude를 연결하는
핵심 다리인 MCP 서버를 구축합니다.

학습 목표

Obsidian MCP 서버 패키지를 설치하고
로컬 환경에서 정상적인 구동 상태를 확인합니다.

핵심 포인트

  • 설치 방법 선택: npm 전역 설치(권장)와 GitHub 소스 빌드 중 선택합니다.
  • 권한 관리: 설치 과정에서 발생할 수 있는 시스템 권한 문제를 해결합니다.
  • 실행 테스트: 서버가 오류 없이 실행되는지 즉시 검증합니다.

완료 기준

터미널에서 npm list -g @mcp-packages/obsidian 명령 입력 시
설치된 패키지 정보가 정상적으로 출력되어야 합니다.
