설정 파일 위치

운영체제별 Claude Desktop 구성 파일의 정확한 경로를 확인하세요. 이 파일에 MCP 설정을 추가해야 합니다.

Windows

%APPDATA% 환경 변수를 사용하여 Roaming 폴더 내의 Claude 경로에 접근합니다.

# 설정 파일 경로 %APPDATA%\Claude\claude_desktop_config.json
# 탐색기 입력 예시 C:\Users\Username\AppData\Roaming\Claude\
macOS

사용자 라이브러리 폴더의 Application Support 내에 위치합니다. 숨김 폴더일 수 있습니다.

# 설정 파일 경로 ~/Library/Application Support/Claude/claude_desktop_config.json
# 터미널 확인 ls ~/Library/Application\ Support/Claude/
Linux

홈 디렉토리의 .config 폴더 내에 위치합니다. 배포판에 따라 차이가 있을 수 있습니다.

# 설정 파일 경로 ~/.config/claude/claude_desktop_config.json
# 터미널 확인 ls -la ~/.config/claude/
