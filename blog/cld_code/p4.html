# Project: AI Agent Workflow Automation

> 이 프로젝트는 TypeScript와 Python을 사용하여 에이전트 시스템을 구축합니다.

## 🛠 Build & Test Commands

- build: npm run build

- test: npm test (Unit tests only)

- lint: npm run lint:fix

- server: python src/server.py

## 📂 Key Directories

- src/agents/: Individual agent logic implementation

- src/shared/: Shared utilities and types

- docs/architecture/: System design diagrams

## 📝 Code Style Guidelines

1. TypeScript: Use strict mode, prefer interfaces over types

2. Error Handling: All async functions must use try-catch blocks

3. Tests: Write tests BEFORE implementation (TDD)

## ⚠️ Critical Constraints

- NEVER commit directly to main branch

- DO NOT expose API keys in logs or code

- ALWAYS update CHANGELOG.md after finishing a task
