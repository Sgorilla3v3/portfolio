매주 월요일 9시 등 특정 시간에 GitHub Actions가 트리거되어 정기적인 지식 베이스 점검 및 리포트 생성을 수행합니다.

보안 및 환경 설정

API 키와 같은 민감한 정보는 GitHub Secrets로 안전하게 관리하며, 워크플로우 실행 시에만 환경변수로 주입됩니다.

.github/workflows/knowledge-management.yml
name: Smart Knowledge Management
on:
  schedule:
    - cron: '0 9 * * 1' # 매주 월요일 9시 실행
  push:
    branches: [main]

jobs:
  update-knowledge-base:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3

      - name: Setup Node.js
        uses: actions/setup-node@v3
        with:
          node-version: '18'

      - name: Install Claude Code
        run: npm install -g @anthropic-ai/claude-code

      - name: Weekly Knowledge Review
        run: |
          claude-code "지난 주 변경된 문서를 분석해서:
          1. 주요 변경사항 요약 및 트렌드 식별
          2. 문서 간 새로운 연결점 제안
          결과를 'Weekly-Review-$(date).md'로 저장해줘"
        env:
          ANTHROPIC_API_KEY: ${{ secrets.ANTHROPIC_API_KEY }}

      - name: Auto-commit changes
        run: |
          git config --local user.email "action@github.com"
          git add .
          git commit -m "Auto: Weekly review"
          git push
