도구 허용 목록 관리

시스템 안전과 에이전트 자율성 사이의 균형 설정

Security First

관리 방법

대화형 승인 (Interactive)

세션 중 권한 요청 시 "Always allow"를 선택하여 현재 세션 동안 권한 부여. 가장 기본적인 방법.

CLI 명령어

/allowed-tools

명령어를 입력하여 실행 중인 세션의 도구 목록을 즉시 추가하거나 제거.

구성 파일 편집 (Persistent)

.claude/settings.json 파일을 직접 수정하여 프로젝트별 영구적인 권한 정책 수립.

권장 보안 정책

  • 기본 원칙: Read-Only

    초기 설정은 읽기 권한만 부여하고, 쓰기 권한은 필요에 따라 점진적으로 확장.

  • 범위 제한 (Scoping)

    전체 파일 시스템이 아닌 src/, tests/ 등 특정 디렉토리로 쓰기 권한 한정.

  • 파괴적 명령 금지

    rm -rf, git push --force 등 되돌릴 수 없는 명령은 자동 실행 목록에서 배제.

설정 파일 예시

.claude/settings.json

{

"commands": {

// 승인 없이 자동 실행할 명령어

"allow": [

"ls",

"cat",

"grep",

"git status",

"npm test"

],

// 실행 전 사용자 승인이 필요한 명령어

"deny": [

"rm",

"curl",

"ssh"

]

},

"filesystem": {

"read": true,

"write": [

"./src",

"./docs",

"./tests"

]

},

"autoCommit": false

}

감사 로그 기록

변경 권한을 부여한 경우, CLAUDE.md에 주요 변경 내역과 관련 PR 링크를 기록하도록 에이전트에게 지시하세요.
