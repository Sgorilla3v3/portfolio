실전 워크플로우: TDD 패턴

AI 에이전트와 함께하는 테스트 주도 개발(Test-Driven Development)의 강력한 루프

High Quality
1

Write Test

테스트 작성 (Red)

요구사항을 코드가 아닌 테스트 케이스로 먼저 정의합니다. AI에게 구현체 없이 테스트만 작성하게 합니다.

  • 예상 입출력 및 예외 정의
  • 엣지 케이스 시나리오 포함
Prompt Example:

User 로그아웃 기능에 대한 테스트를 작성해 줘.

# 아직 기능 코드는 구현하지 마.

2

Run & Fail

실패 확인

테스트가 의도대로 실패하는지 확인합니다. 이 단계는 테스트 코드가 올바르게 동작함을 보증합니다.

  • 테스트 실행 및 실패 로그 확인
  • 잘못된 테스트 여부 검증
Prompt Example:

npm test 실행해 줘.

모든 테스트가 실패하는 것을 확인했어?

3

Make it Pass

구현 (Green)

테스트를 통과하기 위한 최소한의 코드를 작성합니다. 테스트 코드는 절대 수정하지 않습니다.

  • 테스트 코드 수정 금지 (불변)
  • 모든 테스트 통과 목표
  • 코드 구현 -> 테스트 반복 실행
Prompt Example:

테스트 코드는 그대로 두고,

모두 통과하도록 구현만 수정해 줘.

4

Refactor

리팩터링

기능 변경 없이 코드의 구조와 가독성을 개선합니다. 안정적인 테스트가 있어 과감한 수정이 가능합니다.

  • 중복 제거 및 구조 개선
  • 기능 동작 유지 확인
  • 최종 커밋
Prompt Example:

결과는 유지하면서 코드를 정리해 줘.

변수명 개선하고 함수 분리해 줘.
