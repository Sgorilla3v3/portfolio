고급 설정 및 커스터마이징

프로필, 환경, 플러그인을 통한 워크플로우 무한 확장

~/.claude-code/config.json

프로필 시스템

연구자, 개발자 등 역할에 따라 최적화된 명령어 세트와 프롬프트 템플릿을 정의하여 컨텍스트 전환을 가속화합니다.

profiles/researcher.json
"commands": {
  "paper-analysis": {
    "desc": "논문 분석 및 노트 생성",
    "template": "새 논문을 분석해서...",
    "auto_tag": true,
    "create_backlinks": true
  }
}

동적 환경 설정

개발(Dev), 운영(Prod) 환경에 따라 볼트 경로와 안전 장치(Safety Checks)를 동적으로 분리하여 운영합니다.

env/production.json
{
  "environment": "production",
  "vault_path": "/prod/knowledge-base",
  "model": "claude-3-opus-20240229",
  "safety_checks": true,
  "backup_before_modify": true,
  "audit_log": true
}

플러그인 확장

JavaScript를 사용하여 명령어 전처리(Pre) 및 결과 후처리(Post) 로직을 주입하고 기능을 커스터마이징합니다.

plugins/enhancer.js
class ObsidianEnhancer {
  preProcess(cmd) {
    // 최근 파일 컨텍스트 자동 주입
    return cmd + getRecentFiles();
  }
  postProcess(result) {
    // 품질 검사 및 메타데이터 추가
    return addMetadata(result);
  }
}
Usage: claude-code --profile researcher --env production
