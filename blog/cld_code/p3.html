설치 및 초기 설정

NPM 설치부터 MCP 서버 연동까지 3단계 프로세스

Prerequisite: Node.js v18+
1

Claude Code 설치

NPM(Node Package Manager)을 사용하여 전역 패키지로 설치합니다.

# npm을 통한 설치
npm install -g @anthropic-ai/claude-code

# 설치 버전 확인
claude-code --version
설치 완료 시 v0.x.x 이상 버전이 출력되어야 합니다.
2

인증 설정

대화형 인증 또는 환경변수 설정을 지원합니다.

# 방법 A: 대화형 브라우저 인증 (권장)
claude-code auth

# 방법 B: 환경변수 설정 (Mac/Linux)
export ANTHROPIC_API_KEY="sk-ant-..."

API 키는 Claude Console에서 'sk-'로 시작하는 키를 발급받아야 합니다.

3

MCP 서버 설정 (config.json)

Claude Code가 옵시디언 볼트를 인식하도록 설정 파일을 생성합니다.
파일 경로: ~/.claude-code/config.json

경로 설정 주의

'/path/to/your/vault' 부분을 실제 옵시디언 볼트가 위치한 절대 경로로 반드시 변경해야 합니다.

// ~/.claude-code/config.json
{
  "mcpServers": {
    "obsidian": {
      "command": "npx",
      "args": [
        "@mcp-packages/obsidian",
        "/path/to/your/vault" // ⚠️ 실제 경로로 변경
      ]
    }
  },
  "defaultModel": "claude-sonnet-4-20250514",
  "maxTokens": 4096
}
