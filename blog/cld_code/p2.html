Claude Code 소개

에이전트 코딩을 위한 유연하고 강력한 CLI 도구

v 0.1 Preview

무엇인가요?

특정 워크플로우를 강제하지 않는 저수준(Low-level) 에이전트 코딩 도구입니다. 사용자의 쉘 환경을 그대로 상속받아 유연하게 동작합니다.

핵심 구성 요소

CLAUDE.md

프로젝트별 컨텍스트와 규칙을 정의하는 에이전트용 가이드 파일

도구 허용 목록 (Allowed Tools)

파일 시스템 접근 및 명령어 실행 권한을 제어하는 안전 장치

MCP (Model Context Protocol)

외부 데이터 소스 및 도구와 상호작용하기 위한 표준 프로토콜

슬래시 커맨드 (/slash)

반복적인 작업을 템플릿화하여 빠르게 실행하는 기능

확장성

  • 사용자의 Shell 환경 직접 상속

  • gh CLI 연동으로 이슈/PR 관리

  • 커뮤니티 MCP를 통한 기능 무한 확장

고급 모드

헤드리스 모드 -p

CI/CD 파이프라인 등 비대화형 환경에서 실행

Safe YOLO Caution

모든 권한 확인을 건너뛰고 작업 수행 (격리 환경 권장)

멀티 인스턴스

작성자/검토자 분리, Git Worktree 병렬 작업
