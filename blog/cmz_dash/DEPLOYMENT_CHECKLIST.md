## 참고 사항

### Apps Script 수정 시
1. Apps Script 편집기에서 수정
2. 저장 (Ctrl+S)
3. 배포 > 배포 관리
4. **새 버전** 선택 (중요!)
5. 업데이트

### HTML/JS/CSS 수정 시
1. 로컬에서 수정
2. GitHub에 commit/push
3. 자동으로 GitHub Pages 재배포 (1-2분 소요)

### 데이터 업데이트
- Google Sheets에서 직접 수정
- 대시보드는 5분 캐시 후 자동 갱신
- 즉시 반영 필요 시: 브라우저에서 `devTools.clearCache()` 실행
