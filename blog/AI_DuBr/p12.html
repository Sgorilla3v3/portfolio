업무 자동화 워크플로우 (Swimlane)

1. 수집
(Collection)

Cursor

웹 스크래핑

뉴스 사이트, 커뮤니티 게시판 구조 패턴 학습 및 데이터 추출

CSV

데이터 적재

날짜, 제목, 본문, 댓글수 등 구조화된 파일로 저장

2. 전처리
(Preprocessing)

Python

데이터 정제

중복 기사 제거 (Dedup), 광고성 키워드 필터링

Tagging

메타데이터 태깅

매체 유형(보수/진보), 작성자 정보 등 속성 부여

3. 분석
(Analysis)

LLM

프레임 분석

기사에 적용된 핵심 프레임 및 논조(Tone & Manner) 파악

Insight

심층 분석

감성 분석(긍/부정), 주요 의제(Agenda), 핵심 행위자 추출

4. 생성
(Generation)

Genspark

리포트 자동화

일일 여론 동향 보고서(Daily Brief) 초안 자동 작성

Viz

시각화 대시보드

키워드 추이, 감성 분포 그래프 생성

5. 저장
(Storage)

Obsidian

Second Brain

분석 완료 데이터를 지식 베이스(Vault)에 영구 보존

Trust

환각 방지

원본 출처(Source) 링크를 유지하여 데이터 신뢰성 확보

Continuous Feedback Loop

분석 결과의 오류를 수정하여 프롬프트 및 전처리 규칙을 지속적으로 개선
