한 줄 결론

보도자료와 인스타그램은 같은 목적의 채널이 아니다 — 보도자료는 홈페이지 트래픽·기관 인지도를 끌어올리는 역할(두 배포 모두 직후 방문자 최고치), 인스타그램은 실제 프로그램 신청 전환에 더 가까운 채널(게시 직후·+1일 구간에 신청이 몰리는 경향)로 역할이 나뉘는 것으로 보인다. 다만 채널 게시가 한 주에 몰려 있고 모수가 작아(신청 28건) 단정하기는 어렵다 — 다음 캠페인부터는 채널을 분리해 배포해 이 구분을 검증한다.

총 28건 중 6/12(현수막·카페 게시일)에 8건으로 가장 많았다. 같은 날 홈페이지 전체 방문자는 평소 수준(94명)이었던 것과 대조적이다 — 즉 현수막·카페 같은 로컬 채널은 전체 트래픽은 못 움직여도 실제 신청 행동은 끌어냈을 가능성이 있다. 모수가 28건으로 작아 확정하기는 어렵지만, "단독 채널은 효과 없음"이라는 위 결론에 예외로 남겨둘 필요가 있다.

다만 6/12 급증의 원인은 한 가지로 단정하기 어렵다. ① 인스타 1차(6/11) +1일 지연 반응일 수도 있고, ② 6/12가 금요일(주말 직전)이라 행사 참여를 앞두고 신청이 몰린 요일 효과일 수도 있다 — 이 +1일 지연 가설을 다른 채널에도 적용해보면 현수막·카페(6/12)는 +1일인 6/13에 신청 0건으로 패턴이 깨져, 채널 전체에 일관되게 적용되는 규칙은 아니다. 채널이 겹쳐 있고 모수가 작아 현재로서는 두 가설을 가를 수 없다.

채널별 역할 구분

홈페이지 전체 방문자만 보면 인스타그램·현수막·카페는 단독으로 뚜렷한 영향을 주지 못했고, 방문자가 움직인 시점은 보도자료가 작동한 때(단독이면 +3일 지연, 블로그와 겹치면 즉시)뿐이다. 반면 위 프로그램 신청 건수를 같이 보면 다른 그림이 나온다 — 인스타그램 게시 직후(특히 +1일 구간)에 신청이 몰리는 경향이 있다. 즉 보도자료는 "사이트에 와서 둘러보게" 만드는 인지도 채널, 인스타그램은 "신청까지 이어지게" 만드는 전환 채널로 역할이 다른 것으로 추정된다.

한계

  • "인스타그램=신청 전환, 보도자료=인지도"라는 역할 구분은 인과관계가 아니라 시점 일치를 바탕으로 한 추정이다 — 신청 28건이라는 작은 모수, 채널 게시 일정이 한 주에 겹쳐 있다는 점 때문에 확정할 수 없다. 6/12 신청 급증은 인스타 지연 반응일 수도, 금요일(주말 직전) 요일 효과일 수도 있어 경쟁 가설을 가르지 못한다
  • 인스타그램 페이지 단위 노출 폭증(6/11~17)은 게시물 단위 노출(42회)과 크게 어긋나고 활동 종료 즉시 소멸하는 패턴이라 유료 광고 영향으로 추정 — 조직적 도달 효과로 해석하지 않고 게시 시점 정보로만 사용
  • 보도자료·블로그 무관 날짜에도 유사한 규모의 방문자 스파이크가 존재 — 표본이 작아 통계적 확정은 어려움
  • 카카오채널/청도 카톡방 클릭 데이터는 미확보 — 이번 분석에 미포함
  • 전화문의 데이터는 미확보 — 슬랙 기록 체계 가동 후 다음 분석에 포함 예정

02 · DIGITAL

디지털 효과 분석

보도자료가 실제로 어떤 효과를 냈는지 검증하기 위해 거친 가설 검토와 실데이터 분석 과정.

분석 배경

네이버 키워드도구로 확인한 관련 키워드 월 검색량은 평균 약 280회로 모수 자체가 작아, 검색량 증가를 보도자료의 주요 목적·지표로 삼기에는 부적합하다고 판단했다. 프로그램 신청자 수 역시 모수가 작아 통계적으로 의미 있는 변화 검증이 어려워, 홈페이지 유입과 인스타그램 데이터로 분석 범위를 전환했다.

가설 검토 과정

홈페이지 방문자·페이지뷰

평소 일평균 방문자는 60~90명대로 등락이 잦은 노이즈성 데이터다. 1차 보도자료(5/28) 배포 +3일째인 6/1에 방문자 143명, 2차 보도자료(6/16~17)와 청도군 블로그 게시가 겹친 6/16에 156명으로 분석 기간 내 최고치를 기록했다. 다만 보도자료와 무관한 날(6/5, 6/10 등)에도 유사한 스파이크가 있어 노이즈 대비 신호가 강하지는 않다. (상세 시계열은 시점별 유입 분석 탭 참고)

인스타그램 데이터 — 해석 주의

6/11~17 사이 인스타그램 페이지 단위 노출이 499~1,633회로 폭증했다가 6/18에 즉시 4로 떨어졌다. 같은 기간 게시물 단위 노출은 42회에 불과해 수치가 크게 어긋나며, 활동 시작·종료와 함께 즉시 튀고 즉시 사라지는 패턴은 유료 광고의 전형적 특징과 일치한다. 이 노출 수치는 조직적 도달의 증거로 보지 않고, 게시 시점 정보로만 활용한다. 실제로 인스타그램 릴스는 6/11·6/15·6/19 세 차례 게시됐지만, 세 날짜 모두 홈페이지 방문자 변화가 없었다(81명·113명·83명, 모두 평소 수준). 단일 사례가 아니라 세 번 반복 확인된 결과라는 점에서, 인스타그램 단독 게시가 홈페이지 유입으로 이어지지 않는다는 결론에 더 무게가 실린다.

채널 중첩 타임라인

모든 채널을 "최초 게시·배포일" 기준으로 통일해 같은 기준으로 비교한다. 한 주(6/11~6/19) 안에 거의 모든 채널의 시작점이 몰려 있다 — 이것이 "단독 효과 분리 불가"의 시각적 근거다. (보도자료가 매체로 퍼져나간 게재 확산 기간은 매체 분석 탭 참고)

결론

  • 보도자료의 단독 효과는 분리 측정이 어렵다 — 1차는 다른 채널과 겹치지 않아 +3일 지연 반응이 보였고, 2차는 블로그와 같은 날 겹쳐 즉시 반응처럼 보였다
  • 홈페이지 전체 방문자 기준으로는 보도자료가 유입(인지도) 채널, 인스타그램은 단독으로 방문자를 움직이지 못했다(릴스 3회 게시 모두에서 반복 확인)
  • 다만 프로그램 신청 건수(시점별 유입 분석 탭 참고)를 같이 보면 인스타그램 게시 직후 구간에 신청이 몰리는 경향이 있어, 보도자료=인지도/트래픽, 인스타그램=신청 전환으로 역할이 나뉘는 것으로 추정한다 — 단, 인과관계가 아니라 시점 일치 기반 추정이며 모수가 작아(28건) 확정할 수 없다
  • 전화 문의는 정량 측정이 어려우나, 슬랙 기록을 통한 정성적 추적은 가능 (측정 방법론 탭 참고)

한계

  • "보도자료=인지도, 인스타그램=신청 전환" 구분은 시점 일치에 기반한 추정이며 인과관계를 입증한 것은 아니다 — 6/12 신청 급증을 인스타 지연 반응이 아니라 요일(금요일/주말 직전) 효과로 설명할 수도 있어 경쟁 가설을 가르지 못한다
  • 검색량 데이터의 요일·시간대별 분포 미확보 — 기관·공무원 가설 검증 보류
  • 인스타그램 페이지 단위 노출 폭증은 유료 광고로 추정되나 광고 계정 데이터로 직접 확인하지는 못함
  • 채널 배포 일정이 한 주에 몰려 있어 인과관계 분리에 한계 — 다음 캠페인에서 분리 설계 필요

PR 채널별 일반적 특성

이번 캠페인에서 함께 쓰인 채널들이 PR 활동에서 일반적으로 어떤 역할을 하는지 정리한다. 채널마다 강점·한계·적합한 목적이 다르므로, 효과를 같은 기준(유입량)으로만 비교하면 오독하기 쉽다.

핵심 발견 — 회차별 매체 성격이 다르다

  • 2차(6.19 주간)는 통신사(뉴스1)·지역거점매체(매일신문·경북일보)·전국 경제지·시사주간지가 새로 추가되며 권위·신뢰 형성에 유리한 구성으로 전환 — 단, 청도신문·청도투데이는 2차에는 포함되지 않음

모니터링 시스템의 구조적 한계

자체 보도 모니터링 파이프라인(네이버 뉴스 검색 API 기반)으로 자동 집계를 시도한 결과, 실제 게재가 확인된 매체 중 12개가 자동 집계에서 전혀 잡히지 않았다. 네이버 뉴스 검색 API는 네이버와 제휴(검색·콘텐츠 제휴)된 매체만 색인하는 구조이며, 누락된 매체들은 모두 비제휴 소형·지역 인터넷매체다. 즉 보도자료의 실제 도달 범위가 자동 리포트상 수치보다 더 넓을 수 있음에도, 시스템만으로는 이를 입증할 수 없다. 현재는 수동 클리핑(엑셀 리스트)을 병행해 누락을 보정하고 있다.

① 캠페인 파이프라인 — 배포 순서

전화문의 기록 운영 규칙 (신규 제정)

전화문의는 직접 측정이 불가능하므로, 슬랙 기록을 표준화해 정성 지표로 추적한다.

  • 기록 채널 통일: 전화문의 전용 슬랙 채널 1개(예: #문의기록)로 일원화 — 기존에 여러 채널에 흩어져 올라오던 관행 종료
  • 기록 포맷: [날짜] [추정 유입경로] [문의 내용 한 줄] — 추정 유입경로는 "어디서 보고 연락 주셨나요?"를 표준 질문으로 물어 확인. 모르면 "[미확인]"으로 기록(추측해서 채우지 않음)
  • 운영 원칙: 문의를 받은 즉시(같은 날 안에) 기록, 응대자가 바뀌어도 동일 포맷 유지, 캠페인 종료 후 날짜별·경로별로 집계
  • 한계: 문의자 진술에 의존하므로 정확도 100%는 아님 — 정성 보조지표로만 활용

다음 단계 — 데이터 추출 및 분석 실행 가이드

위 측정 방법론을 실제로 어디서·어떻게 추출했는지, 재현 가능한 절차로 정리.

데이터 소스 개요

채널데이터 소스추출 방식
홈페이지관리자 페이지통계 메뉴 → 일자별 요약 CSV 다운로드
인스타그램Meta Business Suite인사이트 → 일별 데이터 내보내기(CSV)
보도자료 게재 시점네이버 뉴스 검색 API + 수동 클리핑news-monitor 파이프라인 조회 + 실제 게재 확인 리스트 대조

채널별 추출 절차

홈페이지 — 관리자 페이지

  • 경로: 관리자 페이지 → 통계 메뉴 → 일자별 요약, 다운로드 항목은 페이지뷰·방문자 중심
  • 월 단위로 끊어 다운로드됨 — 여러 달을 합쳐 전체 기간 시계열 구성 필요
  • 주의: 당일(다운로드 시점) 데이터는 "집계중"으로 표시 → 분석에서 제외

인스타그램 — Meta Business Suite

  • "페이지 활동 일일 분석"(페이지 단위)과 "콘텐츠 게시 시간 요약"(게시물 단위) 2종을 모두 내보내야 함
  • 주의: 두 리포트의 노출 수치가 일치하지 않을 수 있음 — 페이지 단위는 상한선 추정치, 게시물 단위는 확인된 최소치로 구분
  • 날짜 형식이 MM/DD/YYYY로 내려오므로 병합 전 형식 통일 필요

보도자료 게재 시점 — 네이버 API + 수동 클리핑

  • 1차 소스는 실제 게재 확인 리스트(엑셀, 매체명·발행일자·URL) — 네이버 API는 보조 검증용
  • 네이버 뉴스 검색 API는 비제휴 소형매체를 색인하지 않는 구조적 한계가 있어, 단독 사용 시 누락 위험

데이터 병합 및 분석 절차

  • 날짜 키 통일(YYYY-MM-DD) 후 단일 시계열 테이블로 병합
  • 각 채널 게시일 기준 D-3~D+3 구간을 평소 평균과 비교
  • 해석 원칙: 단일 채널 게시일과 정확히 겹치는 변화만 "직접 연관 가능성 있음"으로 표현, 여러 채널이 겹친 구간은 "복합 효과"로 명시

재현 시 체크리스트

  • 홈페이지 관리자 페이지에서 월별 CSV 누락 없이 다운로드(월 경계일 중복/누락 확인)
  • Meta Business Suite 페이지 단위·게시물 단위 리포트 둘 다 내보내기
  • 보도자료 실제 게재 확인 리스트를 1차 소스로 유지
  • 현수막/카페/카톡방 등 오프라인·로컬 채널 게시일은 게시 즉시 수기 기록 — 안 하면 다음 분석에서 복원 불가
