FUNNEL / 세 층이 접합되는 지점

퍼널 7단계 — 정의 · 측정 소스 · 현재 상태

1~4단계는 개발일지의 3단계 퍼널을 확장한 것이고, 5~7단계가 임팩트 측정 방법론의 참여 사다리와 접합되는 지점이다.

단계정의측정 소스현재 상태
1 노출채널에 콘텐츠가 게시되고 최소 1명 이상에게 도달SNS 자체 인사이트, 서치콘솔 노출수, 오프라인은 배포 부수로 근사부분 측정
2 유입사이트 방문 발생, UTM으로 채널 식별 가능GA4 + UTM 파라미터측정 중
3 검토프로그램 상세 페이지 조회, 일정 시간 이상 체류GA4 페이지뷰 · 평균 참여시간 · 이탈률병목 · 이탈 79.0%

PRINCIPLES / 모든 세션이 따르는 3가지 규칙

측정 원칙 3 — 개발일지에서 이미 도출한 결론을 승격

PRINCIPLE 01
전환의 진실은
서버에 있다
GA4의 향상된 측정이 자동 기록하는 form_start / form_submit은 성공 여부와 무관하게 발화한다. 실제 전환은 서버 성공 응답 시에만 발생하는 커스텀 이벤트(apply_submit_success)만 신뢰한다.
근거 — 개발일지 12번, GA4 리포트 분석 중 발견
PRINCIPLE 02
절대수치와 상대비교의
소스를 분리한다
절대수치(몇 명이 신청했는가)는 구글시트 접수 행 수, 상대비교(어느 채널이 잘했는가)는 GA4로 구분한다. 두 값을 정기적으로 교차검증하고 괴리율을 기록한다 (S5 주간 리포트).
근거 — GA4 이벤트 수와 실제 전환의 괴리 확인
PRINCIPLE 03
모수를
먼저 청소한다
클라우드 데이터센터 소재지(Dublin·Prineville·Altoona 등)가 활성 사용자로 잡히는 봇 트래픽, 그리고 내부 관계자 트래픽을 걷어내기 전의 숫자는 의사결정에 쓰지 않는다.
근거 — 청도혁신센터_SEO_수정기획안_v3의 직원 트래픽 필터링 아이디어를 그대로 이식
